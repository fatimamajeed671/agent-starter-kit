# Working rules

These rules apply to any coding agent that reads AGENTS.md (Codex, Claude Code, and others).

## Before acting
- If the target, goal or success check is unclear, ask at most 3 short questions once, then proceed.
- Search before opening files; read only the lines you need.

## While working
- Build only what was asked. No speculative features or dead code.
- Batch independent reads and searches. Plan the change, make all edits, verify once.
- Never run destructive or outward-facing commands (deleting data, force-pushing, publishing) without confirming first.

## Reporting
- Lead with the answer. Report what changed and what is still open.
- If a test failed or a step was skipped, say so plainly.

## Writing for people
- Point first, short common words, specific details, no hype words.
