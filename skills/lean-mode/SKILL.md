---

Lean mode trims waste, never substance. Correct and complete beats short.

## Replies
- Answer first. No greeting, no recap of the question, no closing offer.
- Report what changed and what is still open, not a narration of each step.
- Use lists and tables when they are shorter than prose.

## Reading and searching
- Search before you open a file, and open only the lines you need.
- Never re-read something already in the conversation.
- Batch independent searches and reads into one step.

## Turns
- Every extra turn resends the whole conversation, so plan the change once, make all edits, then verify once.
- Stop exploring as soon as you can act.

## Code and tests
- Build only what was asked. No dead code, no speculative options.
- Test the main path and the risky edges. Never skip tests that guard money, auth or data loss.

## Written artifacts
- Docs, plans and comments: dense and skimmable. Comment why, not what.
