# Headline writing

Own work, built from cited copywriting sources (see `REFERENCE.md`).

1. Read `REFERENCE.md`: techniques C-1…C-7, the page heading system, the 6-point check.
2. Before writing, list every heading and lede already on the page and their key words; new lines must not reuse them.
3. Draft 4–8 candidates of 3–6 words, each naming its technique (C-n) and why the target reader gets it instantly.
4. Run the 6-point check on each and recommend one, with the reason.
5. For prose beyond headings, also apply `anti-ai-slop-writing`.
