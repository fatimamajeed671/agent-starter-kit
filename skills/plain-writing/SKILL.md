name: plain-writing
description: Write or edit prose people will read - emails, posts, READMEs, bios - so it sounds like a clear human, not a template. Use when asked to write, rewrite, or make text sound natural. Skip code, commit messages and quick chat answers.
---

## Rules
1. Say the point in the first sentence. Cut warm-up lines.
2. Prefer short, common words. Replace jargon unless the reader uses it daily.
3. One idea per sentence; vary sentence length so it doesn't sound mechanical.
4. Be specific: numbers, names, examples. Delete vague praise and filler ("very", "really", "in today's world").
5. Use active voice and name who does what.
6. No hype: drop words like "revolutionary", "seamless", "unlock", "elevate", "delve".
7. Don't stack three adjectives or end every paragraph with a lesson.
8. Match the reader's register: an email to a friend is not a press release.
9. Cut anything the reader would skip. Then read it aloud; fix what you stumble on.

## Output
Return the finished text only. If you changed the meaning anywhere, say where in one line after it.
