# Codex and other AGENTS.md agents

These agents have no skills folder. They read an `AGENTS.md` file in the project.

1. Copy `AGENTS.md` from this repo into your project root. If you already have one, paste the sections you want into it.
2. To add a skill, paste the body of its `SKILL.md` (everything below the `---` header) into `AGENTS.md` under its own heading.
3. The Claude Code hooks do not apply here.
